Email Agent Workflow
End-to-end automated invite process — from trigger to completion
Target: <15 min per study

What the Agent Does
  • Fetches candidates from Shortlisting App (first 20 P0, new since last run)
  • Reads Google Sheets manual trackers for additional context
  • Reads specified folder for study materials
  • Generates personalized invite emails via Gemini 3.1 Pro
  • Sends invitation emails through Salesforce Email API
  • Creates child cases in Salesforce for each participant
  • Updates parent case notes with summary
  • Reports results back to RC via chatbot
Key Business Rules
  • P0 Only: Initial outreach targets P0 candidates only
  • Incremental: Only newly shortlisted since last email run
  • RC-Controlled: Up to the number requested by RC
  • No Delete: Agent has read + write access only
  • SLA: All emails sent within 15 minutes of trigger
  • Audit: Full trail logged, no PII stored outside Salesforce
  • Fallback: Notify RC + Pod Lead on any dependency failure
  • GDPR: Zero PII persistence in agent systems

#ScenarioAgent ResponseSeverity

Added: Session Timeout / Interrupted Run

If RC session drops mid-send (browser close, timeout), agent detects interrupted session via state machine and offers Partial Resume — picks up from where it left off. Already-sent emails preserved. RC sees: "Previous run for Study [ID] was interrupted. 8/15 sent. Resume remaining 7?"
